# Photograph credits

Every file in this folder is an openly licensed photograph from Wikimedia
Commons. It is **not** Quest Construction's own work, and none of it shows a
Quest job. Read `README.md` before putting any of it on the site.

All but one require **attribution wherever the photograph is published**. The
credit line for each is given below. A single credits page carrying these lines,
linked from any page that uses one, satisfies the licence.

`demolition-2.webp` is CC0 and needs no credit.
